# Quick Setup Guide

## 1. Create a GitHub Repository

```bash
git init
git add .
git commit -m "Initial commit: AI Wiki setup"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ai-wiki.git
git push -u origin main
```

## 2. Add Your Claude API Key

1. Go to your GitHub repo → **Settings** → **Secrets and variables** → **Actions**
2. Click **New repository secret**
3. Name: `CLAUDE_API_KEY`
4. Value: Paste your Claude API key from [console.anthropic.com/keys](https://console.anthropic.com/keys)
5. Click **Add secret**

## 3. Enable GitHub Pages

1. Go to **Settings** → **Pages**
2. Under "Build and deployment":
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/docs**
3. Click **Save**

GitHub will show your site URL (usually `https://YOUR_USERNAME.github.io/ai-wiki`)

## 4. Test the Setup

1. Edit `queue.txt` and add a term:
   ```
   Neural Network
   ```

2. Commit and push:
   ```bash
   git add queue.txt
   git commit -m "add: Neural Network"
   git push
   ```

3. Go to your repo → **Actions** tab
   - Watch the "Research Terms" workflow run
   - It will automatically research the term and update `docs/entries.json`

4. Once done, visit your GitHub Pages site
   - You should see the new term in the Overview graph and sidebar

## 5. Ongoing Usage

Just edit `queue.txt` with new terms and push:

```bash
# Add terms
echo "Your Term Here" >> queue.txt

# Commit and push
git add queue.txt
git commit -m "add: Your Term"
git push
```

The GitHub Action automatically:
- Detects new terms
- Researches them via Claude API
- Updates `docs/entries.json`
- Commits the results

## Files You'll Use

- **`queue.txt`** — Edit this to add new terms
- **`docs/entries.json`** — Auto-generated by the workflow (don't edit)
- **`docs/index.html`** — The web app (don't edit unless customizing)
- **`.github/workflows/research.yml`** — The research automation (edit to customize prompts)

## Customization

### Change the Research Prompt

Edit `.github/workflows/research.yml`, find the research prompt section, and customize:
- Category names/descriptions
- JSON structure
- Word limits

### Customize the UI

Edit `docs/index.html`:
- Colors: Change CSS `--accent`, `--bg`, etc.
- Fonts: Modify font imports
- Layout: Adjust `--pad`, `--sb-w` (sidebar width)

### Change the Theme

Open the app, click tweaks (bottom-right), and switch between:
- **Aurora** — Clean, modern (default)
- **Signal** — Technical, tight
- **Ember** — Editorial, airy

## Troubleshooting

### Action fails
- Check your API key is correct in Secrets
- View the workflow error logs in Actions tab

### Terms don't appear
- Hard refresh your browser (Ctrl+Shift+R)
- Check GitHub Pages is enabled
- Wait a few minutes for the workflow to finish

### API rate limits
- The free tier is generous (~3M tokens/month)
- Each term costs ~500 tokens typically
